1. 核心基礎題型溫習
1. 常規加法：x + 1 = 2 ➔ x = 2 - 1 = 1
2. 常規減法：x - 1 = 2 ➔ x = 2 + 1 = 3
3. 正係數乘法：2a = 8 ➔ a = 8 ÷ 2 = 4
4. 正分母除法：k3 = 5 ➔ k = 5 × 3 = 15
進階負數及變體題型：
• 1 + x = 2 ➔ x = 2 - 1 = 1
• -1 + x = 2 ➔ x = 2 - (-1) = 3
• -2a = 8 ➔ a = 8 ÷ (-2) = -4
• k-3 = 5 ➔ k = 5 × (-3) = -15
